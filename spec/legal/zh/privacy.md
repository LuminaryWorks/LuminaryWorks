## 1. 角色

LuminaryWorks（启明工坊）是平台运营方。对于平台账号数据、账单与权益记录、政策接受日志和平台安全日志，LuminaryWorks 是控制者。托管服务运行在 OVH。在适用 GDPR 时，上述平台处理受 GDPR 和法国法约束；这些规则不因本政策而减损。登记地址与登记号以 https://luminaryworks.dev/legal 页眉公示为准。平台隐私联系邮箱：admin@luminaryworks.dev。

每个合作产品由其自己的运营方运营。该运营方是产品数据的独立控制者，包括内容、课程、录像、设备数据，以及该产品为提供自身服务而存储的其他数据。某人经由平台登录，并不因此使 LuminaryWorks 成为合作内容的控制者。行使产品数据相关权利时，请通过该产品自己网站上公布的联系方式联系其运营方。行使平台账号或账单相关权利时，请联系 LuminaryWorks。

合作方使用 LuminaryWorks AI 网关时，LuminaryWorks 作为该合作产品运营方的处理者，依合作协议及其数据处理条款，处理提供网关所需的提示词、模型流量和用量计量。该产品使用的控制者仍是合作产品运营方。网关不使 LuminaryWorks 成为合作输出的作者。

在本政策中，「平台运营方」指 LuminaryWorks。「合作产品运营方」指某一合作产品自己的运营方。


## 2. 处理的数据

| 类别 | 示例 | 目的 |
|------|------|------|
| 身份 | Logto `sub`、邮箱、组织成员 | 登录与产品准入 |
| 账单 | 订单、支付尝试（不含完整卡号）、渠道单号、退款 | 结账、税务 / 审计、争议 |
| 政策接受 | `policyVersion`、`acceptedAt`、IP、user agent、`logtoSub` | 记录条款 / 隐私 / Trial 删除政策的明示接受 |
| 地理路由 | 可信 CDN 国家码或连接 IP 的 GeoIP | 选择支付渠道；不是 KYC 文件 |
| 产品内容 | 看板、课程、录像、上传、Doris 演示表 | 提供您使用的合作产品。该数据的控制者是该产品的运营方。 |
| 遥测 / 审计 | 权益检查、管理操作、清理任务 id | 安全、配额、防滥用 |

我们不使用需要服务器采集卡号 / CVV 的支付适配。启用加密货币或本地钱包时，由所列渠道处理。

## 3. 保留

| 数据 | 保留 |
|------|------|
| Logto 身份、订单、支付、审计、Trial 兑换 / 用量记录 | Trial 过期后仍保留，用于账单、欺诈与法定记录 |
| Trial **产品**数据（含该 Trial 的 MinIO 对象与共享 Doris 表） | `endsAt` 后按 [Trial 与数据删除政策](./trial-data-deletion.md) 异步删除 |
| 付费产品数据 | 订阅期内及文档化的宽限；不是永久免费归档 |

**不存在**可让产品工作区在无付费、无窗口内 Trial 的情况下永久保留的 Free 档。

## 4. 存储与处理方（披露）

对象字节存放在运营方托管的 **MinIO 兼容**磁盘（单节点 Pilot；不以公有云 S3 / R2 为权威数据面）。使用 CDN 并不表示对象已离开运营方存储。

共享 Doris（若使用）作为内存封顶的 Pilot 运行。

支付渠道（支付宝、PayPal、微信支付、云闪付 / 银联、Stripe、Coinbase、OKX、BitPay 或人工确认）仅接收完成收款所需的数据。自带 MinIO endpoint 的私有化客户自行负责其环境。

## 5. 共享

我们可能与身份托管、您结账所用的支付渠道、邮件 / 通知投递以及运行控制面所需的处理方共享数据。当您打开某一合作产品时，完成登录所需的身份数据会提供给该产品的运营方，该运营方是其产品数据的独立控制者。我们不出售个人信息。

## 6. 您的选择

账户存续期间您可查看账户与账单。您必须在 `endsAt` **之前** 导出 Trial 数据。不可恢复清理完成后，即使日后付费也无法还原产品内容。

如需删除身份，请使用账户邮箱向 admin@luminaryworks.dev 发送请求。我们会先核验您控制该账户，再删除或匿名化身份资料。法律要求保留的账单、支付与审计记录可以继续保存。
